نظرة عامة

تطبيق React + Vite + Firebase لإدارة الإعلانات، العملاء، المسوقين، والباقات. يدعم المصادقة، قاعدة بيانات Firestore فورية، وتكامل مع Gemini AI.

React 19.2.6Vite 8.0.11Firebase 12.13.0Tailwind 4.3.0TypeScript 6.0.3

قواعد التطوير

  1. اللغة: العربية فقط في التعليقات ورسائل المستخدمين
  2. TypeScript: استخدام // @ts-nocheck في جميع الملفات لتجاوز strict mode
  3. التقسيم: فصل UI عن منطق الأعمال (UI في components/، المنطق في hooks/)
  4. المكونات: مكوّن صغير واحد لكل ملف يستقبل props فقط
  5. Firebase: الإعدادات تُقرأ من .env عبر import.meta.env
  6. التصميم: Tailwind CSS utility classes فقط
