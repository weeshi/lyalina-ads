هذا الفحص يعمل عند فتح الملف من المتصفح مع أذونات محلية. إن لم تظهر النتائج، تحقق يدوياً بفتح الطرفية وتشغيل: node -v، pnpm -v، git --version، npx firebase --version.

الخطوة 2: إدخال إعدادات مشروع Firebase

أدخل قيم مشروع Firebase (من Firebase Console ← إعدادات المشروع ← عام ← تطبيقاتك). يمكنك ملء المفاتيح الحساسة هنا أو تركها فارغة لاستخدام فتحات PASTE_YOUR_... في ملف التكوين.

الخطوة 3: الملفات الجاهزة

انسخ المحتوى الناتج إلى الملف الموافق، أو حمّله مباشرة.

.env
firebaseConfig.ts

الصقه في ملف .env (أضفه إلى .gitignore واجعله خاصاً).

انسخ "القيم المزروعة" أسفل ملف التكوين، أو استبدل الملف كاملاً على المسار src/config/firebaseConfig.ts.

الخطوة 4: الخطوات التالية

  1. تثبيت الاعتماديات: pnpm install
  2. تشغيل خادم التطوير: pnpm dev ثم افتح http://localhost:3000
  3. التحقق من البناء: pnpm build
  4. النشر على Firebase Hosting: pnpm deploy
للتفاصيل الكاملة حول تجهيز مشروع Firebase من الصفر راجع قسم الإعداد على Firebase في دليل التثبيت.
