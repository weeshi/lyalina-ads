التثبيت والتشغيل

ما هي متطلبات تشغيل التطبيق؟
تحتاج إلى Node.js 20+ و pnpm 9+. كما يتطلب تطبيقاً مفعّلاً على Firebase (المصادقة + Firestore) ومفتاح Gemini API للذكاء الاصطناعي. راجع دليل التثبيت للتفاصيل الكاملة.
كيف أثبّت الاعتماديات بعد سحب المشروع؟
شغّل الأمر: pnpm install. سيقوم بتنزيل جميع المكتبات المطلوبة في مجلد node_modules.
ماذا أفعل إذا ظهر خطأ "pnpm: command not found"؟
ثبّت pnpm عالمياً عبر npm: npm install -g pnpm ثم أعد فتح الطرفية وحاول مرة أخرى.
أين أضع إعدادات Firebase؟
أنشئ ملف .env من .env.example وعبّئ متغيرات VITE_FIREBASE_* (المفتاح، النطاق، معرف المشروع، الحاوية، معرف المرسل، معرف التطبيق، معرف القياس).
كيف أشغّل التطبيق محلياً؟
شغّل pnpm dev ثم افتح http://localhost:3000 في المتصفح. سيعمل التطبيق مع إعادة التحميل التلقائي عند تعديل الكود.
كيف أنشئ نسخة الإنتاج؟
شغّل pnpm build لإنشاء مجلد dist الجاهز، ثم pnpm preview لمعاينته قبل النشر.

المصادقة والمستخدمون

كيف أسجّل الدخول كمدير عام؟
استخدم حساب المدير العام المحدد (البريد الإلكتروني ai@ly-tech.ly) وكلمة المرور الخاصة به. يُحدَّد المدير العام بمقارنة البريد الإلكتروني داخل التطبيق.
كيف أضيف مستخدماً جديداً؟
من لوحة الإعدادات (Settings) يستطيع المدير العام إنشاء مستخدمين جدد وتعيين أدوارهم (مدير، موظف، مبيعات، مسوّق). تُخزَّن بيانات المستخدمين في مجموعة system_users في Firestore.
نسيت كلمة المرور، ماذا أفعل؟
استخدم خيار "نسيت كلمة المرور" في شاشة تسجيل الدخول لإعادة تعيينها عبر البريد الإلكتروني، أو اطلب من المدير العام إعادة تعيينها من مشروع Firebase Console.

البيانات والاشتغال بها

أين تُخزَّن البيانات؟
جميع البيانات (الحملات، العملاء، الفواتير، المسوقون، المدفوعات، الباقات، طلبات المسوقين، حركات المحفظة) تُخزَّن في Firestore وتُقرأ لحظياً عبر اشتراكات الهوك useData.
كم عدد أنواع السجلات الأساسية؟
يحتوي النظام على 9 مجموعات رئيسية: campaigns، customers، invoices، marketers، payouts، point_logs، packages، marketer_requests، wallet_transactions.
كيف أبحث وأفلتر البيانات؟
استخدم شريط البحث أعلى الصفحات، وافتح درج الفلترة المتقدمة (AdvancedFiltersDrawer) لتحديد الحالة، النطاق الزمني، والنتائج المطلوبة. يعمل ذلك عبر الهوك useFilters.
هل يمكن استخدام الذكاء الاصطناعي داخل التطبيق؟
نعم، التطبيق يتكامل مع Gemini AI لإنشاء نصوص إعلانات ومساعدة في التحليلات. يتطلب ذلك مفتاح API صالحاً في إعدادات AdsManager.tsx.

النشر والاستضافة

كيف أنشر التطبيق على الإنترنت؟
سجّل الدخول إلى Firebase CLI بـ npx firebase login ثم انشر عبر pnpm deploy. يمكنك أيضاً النشر يدوياً بـ pnpm build ثم npx firebase deploy --only hosting.
ما هو المشروع المربوط للنشر؟
المشروع المربوط حالياً هو lyalina-ads، وموقعه المُستضاف على https://lyalina-ads.web.app.
كيف أضيف تحديثاً جديداً؟
طبّق تعديلاتك في الكود، تأكد من نجاح pnpm build، ثم أعد النشر على Firebase Hosting بنفس الخطوات السابقة.

الأمان وأفضل الممارسات

هل ملف .env يُرفع إلى مستودع Git؟
لا. ملف .env مستبعد عبر .gitignore. لا ترفع أي مفاتيح سرية إلى المستودع حفاظاً على أمان المشروع.
كيف أتأكد من أمان قواعد بياناتنا؟
تحقق من قواعد الأمان في Firebase Console؛ القاعدة الافتراضية الموصى بها تسمح بالقراءة/الكتابة فقط للمستخدمين المصادقين (request.auth != null).
